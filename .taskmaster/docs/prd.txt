Industry-Agnostic Lead Generation System - Make Dynamic Prompts

## Project Overview
Transform the currently hardcoded solar-specific lead generation system to work for ALL industries while maintaining the exact same architecture. The system is fully operational for solar companies and needs minimal changes to become industry-agnostic.

## Current System Architecture (WORKING - DO NOT CHANGE)
- N8N workflow processes email replies → qualifies leads → creates chatbot demos → sends demo links
- Next.js app creates AI assistants and hosts chat interfaces  
- Flow: Webhook → AI qualification → Demo creation → Email with working demo link
- Fully operational at solarbookers.com

## Problem Statement
The create-prototype API has hardcoded solar-specific prompts that prevent it from working with other industries (business funding, insurance, etc.).

## Specific Changes Required

### 1. N8N Workflow Update (AI SDR (direct approach)(3).json)
- **File**: `AI SDR (direct approach)(3).json`
- **Line**: ~170 in "Build Instantly payload" node
- **Current**: API call only sends `companyName`, `location`, `contactEmail`, `contactName`, `title`
- **Required**: Add `industry` field to the API payload from `$json.body?.industry`

### 2. Create-Prototype API Update (route.tsx)
- **File**: `app/api/create-prototype/route.tsx` 
- **Lines**: ~101-193 (assistant instruction section)
- **Current**: Hardcoded "Solar services" and solar-specific prompts
- **Required**: Make prompts dynamic based on industry parameter
- **Specific Changes**:
  - Replace "Solar services" with "[industry] services"
  - Replace solar-specific training with industry-agnostic approach
  - Replace solar-specific FAQ with dynamic industry content
  - Update FIRST message and qualification flows to be industry-aware

### 3. Dynamic Content Generation
- Create industry-specific prompt templates
- Support multiple industries: Solar, Business Funding, Insurance, Real Estate, etc.
- Maintain same conversation flow and structure
- Keep UK idiom/British dialect consistent
