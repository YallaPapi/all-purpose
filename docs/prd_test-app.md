# Test Application

Build a simple task management application with the following features:

## Core Requirements
- User authentication (login/register)
- Task creation and management
- Task status tracking (todo, in-progress, completed)
- Simple dashboard interface
- Responsive design

## Technical Stack
- Next.js with TypeScript
- Tailwind CSS for styling
- Basic state management
- Simple file-based storage or JSON

## Expected Output
A working Next.js application that users can run with `npm run dev` and immediately start managing tasks.
