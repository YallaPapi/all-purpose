## 🚀 Quick Start

### Prerequisites

- Node.js (>= 18.0.0)
- npm or yarn
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd allpurp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. Run the system:
   ```bash
   npm start
   ```
