## 🚀 Quick Start

### 🟢 **For Production Lead System**
1. Read **[SYSTEM_OVERVIEW.md](./SYSTEM_OVERVIEW.md)** for working system overview
2. Check **[ENVIRONMENT_SETUP.md](./ENVIRONMENT_SETUP.md)** for production environment
3. Review **[PARAMETER_MAPPING.md](./PARAMETER_MAPPING.md)** for API integration
4. Use **[DEBUGGING_GUIDE.md](./DEBUGGING_GUIDE.md)** for troubleshooting

### 🟢 **For Meta-Agent Factory Usage**
1. **Enhanced TaskMaster CLI**: `node rag-system/task-master-enhanced.js research "topic"`
2. **Individual Agents**: `cd src/meta-agents/<agent>` and follow agent-specific README
3. **RAG System**: `node rag-system/context-cli.js` for interactive documentation queries
4. **Full System Status**: Review `COMPREHENSIVE_PROJECT_STATUS.md` for complete usage guide

### 🟢 **Meta-Agent Quick Commands**
```bash
# Anti-pattern detection
cd src/meta-agents/ioa && npm run detect-patterns <directory>

# Code generation
cd src/meta-agents/template-engine-factory && npm run generate-template <type>

# Documentation generation  
cd src/meta-agents/5-document-framework && npm run generate-docs <project>

# Production deployment
cd src/meta-agents/vercel-native-architecture && npm run cli build --interactive
```
